Система реализована как веб-приложение с клиент-серверной архитектурой. Серверная часть написана на языке Python с применением фреймворка Django, программный интерфейс построен в стиле REST, данные хранятся в реляционной СУБД MySQL 8.0. Клиентская часть выполнена как одностраничное приложение на библиотеке React. Диаграмма Ганта реализована собственным компонентом и поддерживает четыре типа зависимостей задач, перетаскивание полос, изменение порядка строк и масштабирование.

Разработанная система пригодна для использования небольшими командами без установки клиентского программного обеспечения.

The object of the development is a project management information system intended for small teams.

The system is implemented as a web application with a client-server architecture. The server side is written in Python using the Django framework with a REST API and MySQL 8.0 as persistent storage. The client side is a single-page application built with React. The Gantt chart is implemented as a custom component supporting four dependency types, bar dragging, row reordering and scaling.

The developed system can be used by small teams without installing any client-side software.
