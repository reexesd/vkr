\section{Рабочий проект}

\subsection{Спецификация классов и компонентов программной системы}

В данном разделе приведено описание основных классов и модулей, реализованных в ходе разработки серверной и клиентской частей программной системы. Для каждого класса указаны назначение, ключевые атрибуты или поля, а также перечень методов с модификаторами доступа и кратким описанием. Для модулей, состоящих из набора функций, приводится описание каждой функции.

Серверный код разделен на пакеты моделей, сериализаторов, представлений, фильтров, валидаторов, общих фрагментов поведения, а также модули проверки прав доступа и маршрутизации. Клиентский код разделен на модули обмена с сервером, многоразовые элементы интерфейса, страницы маршрутов, контексты глобального состояния и пользовательские хуки.

\subsubsection{Класс User}

Класс User описывает модель учетной записи пользователя системы. Он наследуется от стандартного класса AbstractUser платформы Django и расширяет его полем отчества и вычисляемым полем полного имени, объединяющим фамилию, имя и отчество. Класс используется при аутентификации, разграничении прав доступа и поиске пользователей по полному имени или логину. От базового класса наследуются методы хеширования и проверки пароля.

\subsubsection{Класс Project}

Класс Project описывает проект как центральную сущность системы. Хранит название, описание, даты начала и завершения, ссылку на создателя. На уровне базы данных задан индекс по названию проекта для ускорения поиска. Через обратное отношение \texttt{members} класс предоставляет доступ к составу участников проекта.

\subsubsection{Класс Task}

Класс Task описывает задачу проекта. Содержит название, описание, даты начала и завершения, порядковый номер задачи в проекте, ссылки на создателя и на проект. Уникальность пары \texttt{(project, number)} запрещает существование двух задач с одинаковым порядковым номером в одном проекте. На поле названия задачи задан индекс. Через обратные отношения \texttt{outgoing\_dependencies} и \texttt{incoming\_dependencies} класс возвращает связи, в которых задача выступает соответственно предшественником и преемником.

\subsubsection{Класс UserColorPalette}

Класс UserColorPalette хранит индивидуальные настройки оформления интерфейса пользователя. Связан с пользователем отношением один к одному. Содержит поле режима темы \texttt{theme\_mode} (\texttt{system}, \texttt{light}, \texttt{dark}, \texttt{custom}) и набор полей с цветами отдельных элементов: фона приложения, поверхности, шапки, активного пункта меню, акцента, полос задач на диаграмме Ганта, стрелок зависимостей, линий сетки, линии текущего времени, сообщений об ошибках, опасных действий и успешных операций.

\subsubsection{Класс TaskViewSet}

Класс TaskViewSet реализует чтение, изменение и удаление задач по глобальному идентификатору. Запросы метода GET без параметра проекта возвращают задачи, созданные текущим пользователем. Запросы PATCH, PUT и DELETE требуют прав редактора или владельца проекта, которому принадлежит задача.

\subsubsection{Класс ProjectDependencyViewSet}

Класс ProjectDependencyViewSet реализует операции над зависимостями между задачами в рамках проекта. Поддерживаются методы GET, POST и DELETE. Метод \texttt{initial} проверяет роль пользователя: для чтения требуется любое участие в проекте, для изменения -- роль редактора или владельца. При создании зависимости в контексте сериализатора передается объект проекта, что используется валидатором для проверки принадлежности обеих задач этому проекту.

\subsubsection{Класс ProjectMemberViewSet}

Класс ProjectMemberViewSet реализует операции над составом участников проекта. Доступ к операциям над участниками имеет только владелец проекта. Изменение и удаление записи об участнике с ролью владельца запрещено. Дополнительное действие \texttt{leave} позволяет участнику самостоятельно покинуть проект.

\subsubsection{Компонент GanttChart}

Компонент GanttChart реализует основное представление календарного плана проекта -- диаграмму Ганта. Отвечает за построение временной шкалы в пределах дат проекта, отрисовку полос задач, стрелок зависимостей, линии текущего времени и штриховки истекшей части полос. Обрабатывает перетаскивание полос задач, перетаскивание левого и правого краев полосы, перетаскивание строки за ручку для изменения порядка задач, режим добавления связей с точками соединения на торцах полос, масштабирование диаграммы в диапазоне 50--400~\% колесом мыши с удержанием Ctrl, кнопками панели инструментов и жестом сведения пальцев. Допустимый диапазон перемещения каждой полосы ограничивается датами проекта и установленными зависимостями.

\subsubsection{Компонент TaskCard}

Компонент TaskCard отображает детальную карточку задачи. Содержит редактируемые поля названия, описания, дат начала и завершения, а также список зависимостей задачи с возможностью добавления и удаления связей. Поля дат ограничены датами проекта и ограничениями из установленных зависимостей.

\subsubsection{Компонент ProjectMembers}

Компонент ProjectMembers реализует управление составом участников проекта. Содержит список текущих участников с их ролями, форму поиска пользователей по логину или ФИО с выводом не более десяти совпадений, элементы изменения роли участника и кнопки удаления. Для текущего пользователя с ролью редактора или наблюдателя предусмотрена кнопка <<Покинуть проект>>.

\subsubsection{Компонент SettingsPanel}

Компонент SettingsPanel реализует страницу настройки цветовой темы. Содержит переключатель режима темы (системный, светлый, темный, пользовательский) и элементы выбора цвета для отдельных компонентов интерфейса в пользовательском режиме. Применение темы выполняется немедленно через изменение CSS-переменных корневого элемента документа без перезагрузки страницы.

\subsection{Системное тестирование}

Системное тестирование программной системы проводилось по сценариям, сформированным на основе прецедентов использования из технического задания. Проверялись основные функции системы: регистрация и аутентификация пользователя, управление проектами и составом участников, работа с задачами и зависимостями, интерактивное редактирование на диаграмме Ганта, настройка цветовой темы.

Тестирование выполнялось в операционной системе Windows 11 с использованием браузера Google Chrome. Серверная часть запускалась локально через uvicorn в режиме ASGI, клиентская -- через сервер разработки React. Все сценарии завершены успешно.
